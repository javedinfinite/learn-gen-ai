# GenAI Reverse-Learning Syllabus

> **Goal:** Become a senior full-stack software engineer with modern GenAI expertise, capable of building, architecting, deploying, scaling, evaluating, and securing production-grade GenAI applications.

> **Learning approach:** Advanced/industry application → underlying concepts → fundamentals where needed.
> Your separate ML course will continue **basic ML → advanced ML**, so this syllabus will not reteach supervised/unsupervised learning fundamentals.

# Learning Format for Every Lesson

Each lesson will follow:

1. **Concept**
2. **Why it exists**
3. **How it works**
4. **Architecture / mental model**
5. **Simple example**
6. **Practical implementation**
7. **Production considerations**
8. **Trade-offs**
9. **Common mistakes**
10. **Interview perspective**
11. **Summary**

Where useful, we will also build the concept into the capstone project.

# Final Target

By completing this track alongside the ML course, the target profile is:

**Senior Full-Stack Engineer**
+
**GenAI Application Engineer**
+
**GenAI System Designer**

You should be comfortable discussing and implementing:

**LLMs → Prompting → Structured Output → Tool Calling → RAG → Embeddings → Vector DB → Advanced Retrieval → Agents → MCP → Guardrails → Evaluation → Observability → LLMOps → Scaling → Cost Optimization → Model Serving → Deployment → GenAI System Design**

while your other course continues:

**ML → Deep Learning → NLP → Transformers → LLM Internals → Fine-Tuning → Advanced ML**

Eventually, the two learning paths converge into a much deeper understanding of the complete AI stack.
