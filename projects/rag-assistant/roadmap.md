Phase 1 — Build the RAG foundation
Start here
- Set up Next.js + TypeScript and Python + FastAPI.
- Connect the two services.
- Create a small sample document collection.
- Implement basic keyword search.
- Add embeddings and semantic search.
- Build the first end-to-end RAG pipeline.




Phase 2 — Improve retrieval
- Metadata filtering and hybrid search.
- Reranking and retrieval optimization.
- Query rewriting.
- Compare results and understand retrieval failures.




Phase 3 — Make it a usable application
- Document upload and processing.
- LLM-generated answers grounded in retrieved text.
- Source citations and insufficient-evidence handling.
- A proper chat interface.




Phase 4 — Production readiness
- Authentication and document-level authorization.
- Automated retrieval and answer evaluation.
- Logging, tracing, latency and cost monitoring.
- Error handling, caching, background processing and deployment.
